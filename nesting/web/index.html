Programs written

  

  

  

    
At the machine

    
    
      
  1. Print RUNSHEET.html from the folder: saw cut list per panel, then per blank its drawing, steps and depths.
    2. 
      
  2. Copy everything in the folder to the root of the diskette.
    3. 
      
  3. DOS: run A:LOAD (copies each program to SRG\<letter>\…, never overwrites, says what it did).
    4. 
      
  4. CNC90 file management: register each program, then open and save it once in the editor.
    5. 
      
  5. Compile. Check every program in the simulator; run the first blank in the air, then on scrap.
    6. 
      
  6. Saw each panel into blanks as the cut list says.
    7. 
      
  7. Per blank: lay it on the scrap against the pins → fixing holes → screw the blank down → screw holes → screw the shapes down → cut the shapes out.
    8. 
      
  8. Optional: A:COLLECT copies the compiler output to A:\OUT\.
