Blanks

A panel saw cuts each panel into blanks. One blank at a time is screwed to the scrap plate on the cups; the shapes are cut out of it and its frame is left over.

Programs for

Program text

  






  
Selection

  
Click a blank on the panel.


  
Heights (Z)

  

  

  
All in mm. The program's stock height is the stack height (scrap + blank); every depth is measured down from the top of the stack. This reading of the control is not yet checked on the machine. To change Z at the shop: edit a height here and generate again.


  
Router (cut job)

  

  
The bit in the head sets the Ø, spindle speed, feeds and depth per pass: see the Tools page.

  


  
Pockets

  

  
Defaults for every pocket group; all placeholders until measured. The bit in the head sets the Ø, speed, feeds, depth per pass and stepover (Tools page). Depth is measured from the top of the blank. Pockets are cut by the blank's B..P program, after the screws and before the cut.

Machine

    

    
Values shown are placeholders until measured at the machine. The panel Layout view is the saw plan (panel corner bottom left), not machine coordinates. The work frame (the area a blank must fit in, long side along machine X) was read from a control config file: verify it on the machine's axis parameter screens.

  






  

  

  

  

    
Bits

    
Every bit the machine may hold, with its numbers; all placeholders until measured. A program takes these numbers from the bit in the head it names. Cells a type does not use show —; optional cells may be left empty.

    

    

    

    

    

  

  

    
Toolheads

    
The machine's heads (fixed list, names from its tool table, not verified on the machine). Each head holds one bit or nothing; a bit may sit in several heads. The router, pockets and drills pick a head in the Plan page's settings.

    

    
Where each head sits, from the control's own spindle table (PARTEC1.PAR on the backup, millimetres from T1), seen from above as you stand in front of the machine: left to right the drill cross, T65, T66 and the X blade, as on the machine. +X to the right and +Y toward the front, as in the programs; that the table's Y runs toward the front like this is not checked. Blades are drawn at their diameter along the cut they make (X blade along X, Y blade along Y). Each head shows its number and the Ø of the bit in it; dashed: no bit. Click a head to pick its bit below. Not checked on the machine: run ZZT4D (post/machine-tests) to confirm which spindle is which.

    

    

  






  
Programs written

  

  

  

  

    
At the machine

    
    
      
  1. Print RUNSHEET.html from the folder: saw cut list per panel, then per blank its drawing, steps and depths.
    2. 
      
  2. Write the folder's DISKETTE folder to an empty diskette (Windows: copy-to-diskette.bat).
    3. 
      
  3. CNC90 file management: Programma Kopie from the diskette (the SORG tree registers the programs). If they do not appear in the compiler list: DOS A:LOAD (copies each program to SRG\<letter>\…, never overwrites), then register each program, open and save it once in the editor.
    4. 
      
  4. Compile. Check every program in the simulator; run the first blank in the air, then on scrap.
    5. 
      
  5. Saw each panel into blanks as the cut list says.
    6. 
      
  6. Per blank: lay it on the scrap, its origin corner (black dot on the run sheet) against the pins, clamp it → run BnnD (all holes, still clamped) → screw the blank down through the fixing holes and each shape through its screw holes → take the clamps off → run BnnC (cut the shapes out) → unscrew.
    7. 
      
  7. Optional: A:COLLECT copies the compiler output to A:\OUT\.
