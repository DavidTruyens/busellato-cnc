Programs written

  

  

  

    
At the machine

    
    
      
  1. Print RUNSHEET.html from the folder: panel drawings, steps and depths.
    2. 
      
  2. Copy everything in the folder to the root of the diskette.
    3. 
      
  3. DOS: run A:LOAD (copies each program to SRG\<letter>\…, never overwrites, says what it did).
    4. 
      
  4. CNC90 file management: register each program, then open and save it once in the editor.
    5. 
      
  5. Compile. Check every program in the simulator; run the first panel in the air, then on scrap.
    6. 
      
  6. Per panel: fixing holes → screw the panel down → place the shapes → screw holes → screw the shapes down → cut.
    7. 
      
  7. Optional: A:COLLECT copies the compiler output to A:\OUT\.
